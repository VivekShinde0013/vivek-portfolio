# Fresh visual theme

This version uses a fresh **Midnight Atelier** palette instead of the previous cyan/purple-only scheme:

- Midnight Ink: `#08090F`
- Deep Slate: `#10131C`
- Mint: `#62F5C1`
- Coral: `#FF7A90`
- Periwinkle: `#8EA7FF`
- Warm Ivory: `#F5F0E6`

The 3D workshop keeps its technical identity while using mint for active systems, coral for real-world signals/attention, and periwinkle for secondary depth.
